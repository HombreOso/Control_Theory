# Control Systems Brief — General Control Systems — 2026-09-25

## Research Papers
- [Three High Performance Global Tracking Composite Adaptive Controllers](https://arxiv.org/abs/2609.27010) (arXiv, Cervantes-Perez, Romero, Ortega et al., posted Sept 24, 2026) — Proposes and experimentally validates three composite adaptive control designs for Euler-Lagrange (robotic/mechanical) systems, aimed at global tracking with faster parameter convergence than standard adaptive schemes.
- [Safety-Filtered Distributed Koopman-MPC](https://arxiv.org/abs/2609.27463) (arXiv, Zhang, Li, Lin, Sun, posted Sept 24, 2026) — Combines Koopman operator-based linear surrogate modeling with distributed model predictive control and a safety filter, for multi-agent systems with nonlinear dynamics that need formal safety guarantees.
- [Gray-Box Model Predictive Control for Articulated Dump Trucks](https://arxiv.org/abs/2609.27597) (arXiv, Shahirpour et al., posted Sept 24, 2026) — Develops a gray-box (physics + learned-component) MPC formulation for heavy articulated vehicles, blending first-principles vehicle dynamics with data-driven correction terms for improved path-following control.
- [Optimal Guidance with Terminal Intercept-Angle Constraints](https://arxiv.org/abs/2609.28381) (arXiv, Azaryahu, Shaferman, posted Sept 24, 2026) — An optimization-based guidance/control law enforcing a specified terminal intercept angle alongside acceleration limits — relevant to constrained trajectory-tracking control problems more broadly, not just aerospace intercept.

## Use Cases
- [Real-time decentralized model predictive control for cooperative multi-robot object transport: experimental validation](https://www.nature.com/articles/s41598-026-41881-w) (Scientific Reports, March 22, 2026) — Two differential-drive robots cooperatively transport an object using decentralized nonlinear MPC running in real time on embedded hardware, achieving accurate tracking, constraint satisfaction, and robustness to disturbances — a concrete example of MPC moving from simulation to real embedded robotics hardware.

## Software & Tools
- [i-pIDtune 2.0: An Updated Interactive Tool for Integrated System Identification and PID Control](https://www.sciencedirect.com/science/article/pii/S2405896324007225) (ScienceDirect) — An updated open interactive tool that couples system identification with PID controller design/tuning in one workflow, aimed at practitioners doing loop tuning rather than pure theorists.
- [Choosing The Right PID Tuning Software: What To Look For In 2026](https://www.picontrolsolutions.com/blog/choosing-the-right-pid-tuning-software-what-to-look-for-in-2026/) — A 2026 buyer's-guide roundup of PID tuning software criteria, useful as a practical tools overview for someone moving from building/process controls into formal controls engineering.
