## Software & Tools

- GNU Octave 11 (released February 2026) reworked its package manager with keyword search and SHA256 verification, dropping the old `pkg -forge` syntax — Octave Forge's control-systems and signal-processing packages remain a free MATLAB/Simulink alternative for classical control work. [RunMat blog](https://runmat.com/blog/free-matlab-alternatives)
- RunMat, an open-source JIT-compiled numerical computing environment, ships 1,000+ built-in functions spanning control, signal processing, optimization, and ODE solving with automatic GPU acceleration — positioned as another free alternative to MATLAB for control-systems scripting (note: it does not replicate Simulink's graphical block-diagram modeling). [RunMat blog](https://runmat.com/blog/free-matlab-alternatives)

## Use Cases

- Deep reinforcement learning combined with classical PID control improved hydraulic servo performance in injection-molding machines, with the DRL layer correcting for nonlinearities that fixed-gain PID alone struggles with. [Scientific Reports](https://www.nature.com/articles/s41598-025-05904-2)
- A PID tuning approach using a "multistrategy enhanced dung beetle optimizer" combined with a backpropagation neural network was applied to DC motor control, aiming to improve transient response and disturbance rejection over manually tuned PID. [Scientific Reports](https://www.nature.com/articles/s41598-024-79653-z)

## Research Papers

- "Robust Adaptive MPC in the Presence of Nonlinear Time-Varying Uncertainties: An Uncertainty Compensation Approach" combines an L1 adaptive controller (for matched uncertainty) with an LMI-based robust feedback controller (for unmatched uncertainty) inside an MPC layer, deriving uniform error bounds to tighten constraints while preserving guarantees; validated on flight control and spacecraft landing simulations. [arXiv 2603.00283](https://arxiv.org/abs/2603.00283)
- "Adaptive Tube MPC: Beyond a Common Quadratically Stabilizing Feedback Gain" extends tube-based MPC robustness beyond the usual single fixed feedback-gain assumption. [arXiv 2603.15912](https://arxiv.org/abs/2603.15912)
- "T2S-MPC: Time-Embedded Online Adaptive Model Predictive Control for Time-Varying Dynamics" proposes an online-adaptive MPC formulation that embeds time explicitly to handle systems whose dynamics change over the prediction horizon. [arXiv 2605.24852](https://arxiv.org/abs/2605.24852)
- "An Overview of Systems-Theoretic Guarantees in Data-Driven Model Predictive Control" surveys stability, robustness, and constraint-satisfaction guarantees for MPC schemes built directly from data rather than an explicit model. [Annual Reviews in Control](https://www.annualreviews.org/content/journals/10.1146/annurev-control-030323-024328)
