## Research Papers
- A deep Koopman-operator MPC scheme automates the full wheel-loader "V-cycle" (dig, haul, dump) for heavy construction equipment, learning a linear latent-space model of the machine's nonlinear dynamics to make real-time MPC tractable. [Wheel-loader V-Cycle Automation with Deep Koopman MPC](https://arxiv.org/abs/2609.26580)
- A learned air-ground motion controller uses temporal mode switching and cross-terrain tracking to let a single robot transition between flying and driving locomotion modes. [Learning Air-Ground Motion Control with Temporal Mode Switching and Cross-Terrain Tracking](https://arxiv.org/abs/2609.26564)
- Model predictive path integral control combined with a bidirectional LSTM learned dynamics model improves manipulation of deformable linear objects such as cables and ropes. [Manipulation of Deformable Linear Objects Using Model Predictive Path Integral Control with Bidirectional Long Short-Term Memory Learning](https://arxiv.org/abs/2609.26238)
- A data-upcycling approach shows that deliberately imperfect demonstration data, properly leveraged, can improve high-precision robotic manipulation performance. [Imperfection for Precision: Upcycling Imperfect Data for High-Precision Robotic Manipulation](https://arxiv.org/abs/2609.26672)
