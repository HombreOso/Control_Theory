## Research Papers
- "Perception-and-Action System for Humanoid Robot Task Execution in Construction" (Syracuse University) introduces Humanoid-PoseNet, which retargets human demonstration poses into robot-feasible poses, and Humanoid-ActionNet, a teacher-student RL framework that turns those poses into stable whole-body actions. Tested on carrying pipe, holding bricks, and lifting boxes, it achieved an average motion-tracking error of 82.45 mm. [ScienceDirect](https://www.sciencedirect.com/science/article/pii/S1093968726030938)
- "Koopman-Accelerated Model-Based Diffusion for Real-Time Robot Control" lifts robot states into a linear (Koopman) space so trajectory optimization reduces to matrix-vector multiplications, enabling real-time planning at 14.7 ms per update and outperforming linear alternatives on manipulation tasks. [arXiv:2609.28920](https://arxiv.org/abs/2609.28920) (submitted Sept 24, 2026)
- "AeRSoM: An Aerial Rigid-Soft Integrated Manipulator for Contact-Rich Manipulation" presents an aerial manipulator combining rigid and soft structural elements for robust contact-rich manipulation tasks. [arXiv:2609.28044](https://arxiv.org/abs/2609.28044v1)
